# Student Feedback System

A frontend-based Student Feedback System designed to provide a simple and structured interface for students to share feedback about their courses and faculty.

## Overview

The Student Feedback System is a web development project that demonstrates the design of a digital academic feedback portal. It provides an interface for students to navigate a dashboard, select courses, and submit feedback through structured forms.

## Features

- Student login interface.
- Student dashboard layout.
- Course and faculty selection interface.
- Course feedback form.
- Teaching quality and course content rating fields.
- Additional comments and suggestions section.
- Faculty/Admin feedback view interface.
- Structured and user-friendly interface.

## Technologies Used

- HTML5 – Structure and content of web pages.
- CSS3 – Styling, layout, and visual presentation.

## How to Run the Project

1. Clone or download this repository.
2. Extract the downloaded files.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your web browser.
5. Explore the available pages and feedback interface.

You can also use the Live Server extension in Visual Studio Code.

## Learning Outcomes

- Structuring web pages using HTML.
- Styling interfaces using CSS.
- Designing forms and dashboard layouts.
- Organizing webpage content and navigation.
- Understanding frontend web development fundamentals.

## Project Scope

This version focuses on frontend design and interface development. Backend authentication, database connectivity, and persistent feedback storage are not currently implemented.
