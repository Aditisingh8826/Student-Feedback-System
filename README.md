# Weather Information Dashboard

A web-based weather dashboard that allows users to search for a city and view its current weather conditions.

## Features
- Search weather information by city name.
- Display current temperature.
- Show humidity and wind speed.
- Display feels-like temperature.
- Show weather conditions with corresponding icons.
- Input validation and error handling.
- Loading indicator while fetching weather information.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## APIs
This project uses:
- Open-Meteo Geocoding API to retrieve city coordinates.
- Open-Meteo Forecast API to retrieve current weather information.

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser or use the VS Code Live Server extension.
4. Enter a city name and click **Get Weather**.
5. View the retrieved weather information.

An active internet connection is required for API requests.

## Purpose
This project was developed to practise frontend web development, JavaScript, API integration, asynchronous requests, and dynamic data presentation.
